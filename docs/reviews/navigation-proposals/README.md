# Propostas de navegação — 03/11/2026

Abra [menu-a.html](menu-a.html) ou [menu-b.html](menu-b.html) no navegador. Arquivos estáticos, sem dependências, backend ou dados pessoais. HTML, CSS e comportamento ficam separados.

São propostas para avaliação; não substituem o menu do aplicativo. O conteúdo do catálogo é demonstrativo. O protótipo não salva respostas, filtra questões nem altera contas.

- **A, recomendada:** menu lateral agrupado no desktop; cabeçalho compacto com Menu no celular; conta reunida em um controle. Preserva os dez destinos e seus nomes. Apoio é recolhível e revela a opção ativa.
- **B:** mesma organização no desktop, cinco raízes fixas no rodapé do celular. Questões, Treinos, Revisão e Menu abrem os destinos correspondentes. Exige mais mudanças de hábito e espaço reservado para não sobrepor ações do treino.

Para implementar, usar componentes Angular existentes, rotas estáveis, foco de retorno, marcação de destino atual e tokens do produto. Validar primeiro o menu A em 320/390/768/1440 px. Estes arquivos não são uma arquitetura nova para o aplicativo.
